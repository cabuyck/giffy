**Learnings for future iterations:**
- Socket.io Server type arguments order is critical: `Server<ClientToServerEvents, ServerToServerEvents, InterServerEvents, SocketData>`
- The Server type parameters are: (listen events, emit events, inter-server events, socket data)
- Character set `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` avoids ambiguous characters (I, O, 1, 0)
- Use socket.join(roomCode) to enable targeted broadcasts with io.to(roomCode)
- Track socket associations in separate Maps to handle disconnects without needing socket.data
- When host disconnects in lobby, promote first remaining player to host
